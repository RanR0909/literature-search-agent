# lit-navigator · 跨国文献检索领航员

清华大学 AI Agent 创新大赛参赛项目（2026-06 ~ 09）的工作目录。**本项目所有材料只放这里，不进 Obsidian 知识库。**

## 项目一句话

本科生做世界史/区域国别研究的最大瓶颈是"不知道文献在哪"。智能体通过追问明确国别/时段/主题/语言能力，基于分区域文献平台知识库输出可执行的检索方案（平台路线图 + 历史术语本地化词包 + 访问路径），开放接口平台可直接代查。

## 目录

- `审阅/` — 待用户审核的清单与草稿
  - `图书馆人文社科数据库清单-待审.md` — 首批原料：867 库分区归类（2026-08-07 抓取，508 入正文）
- `data/lib-raw/` — 图书馆数据库导航接口的原始 JSON（历史学 + 10 学科 + 11 语种 + 报纸/档案类型）

## 关键事实

- 平台：清小搭（xiaoda.tsinghua.edu.cn），智能体建在内嵌的 Coze 开源版；知识库放"知识库共创平台"（kb-console）；外部 API 走插件
- 图书馆数据接口：`POST ecollection.lib.tsinghua.edu.cn/databaseguide/guide/listDatabaseguideBySubjectAndTypeIndex1`（JSON body：firstSubject / language[ger,fre,jpn...] / databasetype / pageNum / pageSize）
- 发现：俄语区人文馆藏几乎空白——智能体"校外公开平台指路"价值的实证，答辩可用
