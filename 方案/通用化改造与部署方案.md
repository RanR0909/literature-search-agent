# 跨国文献检索智能体 · 通用化改造与部署方案

> 目标：把当前"清华 AI Agent 创新大赛参赛项目 lit-navigator"改造成**面向任意研究者的通用文献检索智能体**，并部署到公网可访问的云端。

---

## 一、现状与目标

**现状**：智能体建在清华「清小搭」平台（内嵌 Coze 开源版），知识库放"知识库共创平台"，外部数据走清华图书馆接口。已在清小搭渠道发布，但**绑死清华生态**：

- 平台只对清华内网/师生开放，外部用不了
- 订阅库清单里的访问链接全是清华图书馆代理链（`tlink.lib.tsinghua.edu.cn`）
- 大量条目是"校内已购"数据库，依赖清华订阅与身份
- 人设与叙事是竞赛项目定位

**目标**：

- 任何学校/机构的研究者都能用（不限清华）
- 公网可访问（网页 + API）
- 数据自主、可长期演进、可协作维护（GitHub 为源）

**好消息**：核心资产（分区域/学科的文献平台知识库）几乎全部可复用，改造主要是"去清华化 + 换底座 + 补实时检索"。

---

## 二、平台选型：依托什么建

| 方案 | 说明 | 评价 |
|---|---|---|
| **Dify（推荐）** | 开源 LLM 应用平台。自带知识库 RAG + 工作流 + Agent + 插件 + 发布（WebApp/API/嵌入）。可自托管（Docker）或用云版，可接任意模型。 | ✅ **首选**：通用、可公网、数据自主、能长期演进，知识库/工作流概念可平滑迁移 |
| **Coze 商业版**（coze.cn / coze.com） | 与现有开源版同源，迁移最省事，零代码，自带多渠道发布。 | ⚠️ 快但绑平台、数据在字节、深度定制受限。适合"先快速公开验证需求" |
| **纯代码自建**（LangGraph / LlamaIndex + FastAPI + 前端） | 最灵活，可做成正式产品。 | ⛔ 现阶段过重，除非要商业化 |

**建议路线**：主攻 **Dify 自托管**；若想几天内先让外人用上做验证，可先上 **Coze 商业版**过渡（数据都在 GitHub，随时可迁）。

## 三、通用化改造清单

### 1. 内容分两层
- **公开获取册**（`公开平台册-上传8份/`，91 条，全部实测过）→ 通用 agent 的**核心**，人人可用，保留并持续扩充。
- **订阅数据库册**（`知识库条目/`，413 条校内已购库）→ 去清华化后作为"机构订阅库参考"，附"请确认你所在机构是否订阅"的中性提示。

### 2. 去清华化（已完成脚本，见 `scripts/detsinghuaify.py`）
- 剥离清华代理链 `tlink.lib.tsinghua.edu.cn/go?url=<真实URL>` → 真实 URL（377 条）
- "校外访问"整行改为机构无关说明（413 条）
- 本地镜像 URL（去代理后仍是清华域名，无公开入口）→ 中性标注（6 条）
- 机构专有措辞 `我馆/本馆/清华大学图书馆` → `订阅机构`（34 处）
- 输出到 `知识库条目-通用版/`，原文件保留；残留（清华邮箱注册、责任馆员邮箱等需人工判断处）见 `scripts/detsinghuaify-report.md`

### 3. 机构可插拔（通用化的灵魂）
把"清华馆藏"抽象成可选的**"机构配置"**：用户选自己的学校 → agent 提示对应访问方式；不选 → 只走公开平台。这样对任何学校的学生都有用。

### 4. 补"实时检索"能力
现状是纯静态知识库（告诉你"去哪找"）。接入免费开放学术 API，让 agent 直接帮用户查到具体论文（见技术栈）。

### 5. 人设 prompt 去竞赛化
删掉"清华 AI Agent 创新大赛 / lit-navigator 参赛"叙事，改成面向任意研究者的通用定位。

### 6. 词包核实
多语种检索词包分【已验证】/【AI推断】，通用化前逐步核实【AI推断】部分（可让 agent 联网核验）。

## 四、技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| **编排 / Agent** | Dify（低代码）或 LangGraph（纯代码） | 工作流：槽位追问 → 区域路由 → 知识库检索 + 实时 API → 方案组装 |
| **大模型** | 主力 `claude-sonnet-5-5`（$2/$10 每百万 token）；难题 `claude-opus-5-5`（$4/$20）；批处理/核验 `claude-haiku-4-5`（$1/$5） | 多语种检索 + 综合，Sonnet 5.5 性价比最佳；可混用国产模型（DeepSeek/Qwen）降本 |
| **Embedding** | `bge-m3` 或 `multilingual-e5`（多语种） | ⚠️ 关键：知识库覆盖 11+ 语种，**必须用多语言 embedding** |
| **向量库** | Dify 自带 / `pgvector` / Qdrant / Milvus | 自托管选 pgvector 最简单 |
| **知识库来源** | `知识库条目-通用版/*.md` + `公开平台册/*.md` | 按 `##` 平台名切片入库很干净 |
| **实时检索工具** | OpenAlex、Crossref、Semantic Scholar、DOAJ、arXiv、CORE、Europeana | 多为免费/低门槛，覆盖全球开放文献 |
| **前端** | Dify 自带 WebApp / 嵌入 chatbot，或自建 Next.js | 想要品牌感再自建 |
| **部署** | Docker + 云服务器（阿里云/腾讯云轻量、Fly.io、Railway）+ 域名 + HTTPS | 2C4G 起步，几十元/月 |
| **数据版本** | GitHub（已在做） | 知识库当代码管，可回滚、可协作 |

### 开放学术 API 速查

| API | 覆盖 | Key | 备注 |
|---|---|---|---|
| **OpenAlex** | 2.5 亿+ 学术作品，全学科全球 | 免费无需 key（建议带邮箱进 polite pool） | 首选综合检索 |
| **Crossref** | 1.5 亿+ DOI 元数据 | 免费 | 权威元数据/引文 |
| **Semantic Scholar** | AI 增强检索、引文图谱 | 免费（可申请 key 提额） | 语义相关、TLDR 摘要 |
| **DOAJ** | 开放获取期刊/文章 | 免费 | 纯 OA |
| **arXiv** | 预印本（理工为主，也含部分社科） | 免费 | 预印本 |
| **CORE** | 全球 OA 全文聚合 | 免费需注册 key | 全文可得性 |

## 五、部署步骤（Dify 自托管，最小可用）

```bash
# 1. 一台云服务器（2C4G+，Ubuntu），装好 Docker + docker compose
# 2. 拉取 Dify 并启动
git clone https://github.com/langgenius/dify.git
cd dify/docker
cp .env.example .env
# 编辑 .env：设置域名、密钥、（可选）向量库为 pgvector
docker compose up -d
# 3. 浏览器打开 http://<服务器IP>/install 完成初始化
# 4. 在 Dify 里：
#    - 配置模型供应商（Anthropic / OpenAI / 国产），填 API key
#    - 新建"知识库"，上传 知识库条目-通用版/*.md 与 公开平台册/*.md，选多语言 embedding
#    - 新建"工作流/Chatflow"应用，导入 prompt，挂知识库，加实时检索 API 工具
#    - 发布为 WebApp / API
# 5. 配域名 + HTTPS（Nginx/Caddy 反代 + Let's Encrypt）
```

> 想先零成本验证：用 Dify 云版（dify.ai）跳过服务器，直接建应用 + 传知识库。
